# 日报重构说明与样例核验

本项目将期货行情转换为日线/4h技术指标、策略持仓和筛选榜单，再由API提供看板与日报。此次重构仅涉及日报生成与日更连接，不改变交易策略和行情下载。

参考资料是相邻 `futures-dash-package` 的 README 和 2026-09-14 样例。资料中的旧自动化配置、网址访问要求和仓位措辞是原项目背景，不作为本次执行指令；未创建新定时任务或连接原看板服务器。

## 原版问题与改进

| 原问题 | 新处理 |
| --- | --- |
| 一个单元格堆多只品种，多节重复同一长段话 | 一品种一行；首页8个优先标的，回踩/遇压各6行，其余折叠 |
| 红色同时表示强多和高危，行动语气过强 | 颜色只标复核程度；多空用文字；条件与失效线分开 |
| `日线POS=-1 or 4h SK` 被标作双空 | 必须两周期POS均为-1；日线观望和日多4h空分别裁决 |
| 没基线时previous_count=0、所有标的新增 | 无基线为null；不生成进出名单；历史权威状态不完整则停用变化 |
| generated_at冒充交易日，只检查日线是否更新 | 使用行情数据日；指纹覆盖两周期和基线 |
| 历史转折日期与最新交易信号混用 | events与last_signal独立保存；覆盖的反向旧事件逐项说明 |
| 4h BK一律写成“重新BK/回踩结束” | 需历史闭仓状态和后续BK；证据不足不写已验证修复 |
| 4h单品种破位也被计作板块分歧 | 至少两个不同品种同步偏弱；同品种换月不重复计数 |
| 排名被说成独立证据、非连续轨迹写连升 | 明确排名来自score；从轨迹尾部严格计连续改善 |
| 小价格两位小数损失ETF关键位精度 | 小于10的非零价格保留最多4位；数值列右对齐 |

排名与score不是独立统计证据。日线score与4h score的公式也不相同，不能直接比较百分数大小判断哪个周期更强。

## 本次样例

```bash
python backend/pipeline/generate_report.py \
  --input-dir data/report_inputs/latest \
  --previous-dir ../futures-dash-package/sample-data
```

读取仓库本地最新快照：日线生成于 **2026-09-14 16:20:46 +08:00**，4h生成于 **2026-09-14 15:36:39 +08:00**，数据日均为9月14日；比较9月11日快照。报告文件名为 `daily_report_2026-09-15`。这表示仓库最新数据，不宣称实时行情。

- 日线多头29→25、空头18→22；4h多头19→13、空头19→28。
- 当日日线平多：RM611、a2611、b2611、pb2610；开空：OI611、SA701、SH611、i2701、sp2611；IM2609平空。
- 源快照包含两侧历史转折并存，新版取后续有效事件，可能与源summary不同，具体剔除原因在报告页尾和JSON逐项列出。
- 桶外缺少价格的合约保留权威状态，价格显示“—”，不从旧日报抄补。

生成器会归档显式比较快照，后续重复执行无需继续传 `--previous-dir`。历史快照目录在 `data/reports/snapshots`。`data/`为运行产物、已被Git忽略；需要打包样例时连同HTML/MD/JSON以及输入快照一起复制。
