# 文华麦语言策略代码详解（逐行注释版）

> 本文档对三段麦语言代码（ZXGL 周线过滤器、XDD 强弱标尺、主策略）进行完整注释。
> 每部分先给出**变量字典**，再给出**逐行注释后的代码**，最后说明**该部分产生的信号及含义**。

---

## 0. 整体架构

```
┌─ ZXGL（跑在周线上，被主策略 #IMPORT[WEEK,1,ZXGL] 引用）
│    → 输出 AA / ZZ / TT：周线方向 + 是否盘整
│
├─ XDD（跑在文华商品指数 7186 上，被主策略 #CALL [7186,XDD] 引用）
│    → 输出 K1 / K2 / JC1 / JC2：大盘的涨幅、跌幅、位置分层
│
└─ 主策略（跑在你要交易的具体品种上）
     → 综合外部数据 + 本品种形态 + 持仓量，发出 SK / BK / BP / SP 交易指令
```

**核心思想：周线定方向 → 形态（M头/W底）定进场 → 盘整过滤避震荡 → 对比文华指数看相对强弱 → 持仓量（OPI）做资金确认。**

---

## 1. ZXGL —— 周线方向过滤器

### 1.1 变量字典

| 变量 | 类型 | 含义 |
|---|---|---|
| `AA` | 输出信号 | 周线收盘价低于 7 周均线 → **周线偏空**，允许做空的"许可证" |
| `ZZ` | 输出信号 | 周线收盘价高于 7 周均线 → **周线偏多**，允许做多的"许可证" |
| `TT` | 输出信号 | 周线**不处于盘整**（PANZHENG=0）→ 允许开仓的"波动许可证" |
| `ZD` | 中间量 | 7 周期价格中枢 =（7 周期最高价 + 7 周期最低价）/ 2 |
| `K1` | 中间量 | 现价相对 7 日最低价的涨幅（百分比小数） |
| `K2` | 中间量 | 现价相对 7 日最高价的跌幅（负数或 0） |
| `JC1` | 中间量 | 7 日区间 5 等分后，现价所在的层数（1~5，贴顶可能为 6） |
| `JC2` | 中间量 | 当日单根 K 线 5 等分后，收盘价所在层数（1~5） |
| `PANZHENG` | 隐含变量 | 盘整判定：7 周期振幅 ÷ 7 周期均价 < 3% 即为盘整（需在公式内定义） |

### 1.2 注释后代码

```mylanguage
// ============ ZXGL：周线过滤器（在周线上运行，被主策略跨周期引用） ============

AA: C<MA(C,7);
// 收盘价 < 7周期均线 → 周线级别偏弱，输出"空头方向许可"
// 主策略中引用为 AA1，只有 AA1 为真才允许开空单

ZZ: C>MA(C,7);
// 收盘价 > 7周期均线 → 周线级别偏强，输出"多头方向许可"
// 主策略中引用为 ZZ1，只有 ZZ1 为真才允许开多单

TT: PANZHENG=0;
// 周线不盘整 → 输出"波动许可"
// PANZHENG 需在 ZXGL 内部定义（与主策略同公式）：
//   PANZHENG := (HHV(H,7)-LLV(L,7))/MA(C,7) < 0.03;
// 即 7 周期振幅不足均价 3% 时视为死盘，TT=0 禁止开仓

ZD:=(HHV(H,7)+LLV(L,7))/2;
// 7周期中点：价格强弱分水岭
// 收盘价在 ZD 上方 = 处于近一周上半区（偏强）；下方 = 下半区（偏弱）

K1:=(C-LLV(L,7))/LLV(C,7);
// "涨幅"指标：现价相对 7 日最低价弹起来多少
// 注意分子用最低价 LLV(L,7)、分母用最低收盘价 LLV(C,7)，数值会略偏大

K2:=(C-HHV(H,7))/HHV(C,7);
// "跌幅"指标：现价距 7 日最高点回落了多少（结果 ≤ 0，越负跌得越深）

JC1:=INTPART((C-LLV(L,7))/((HHV(H,7)-LLV(L,7))/5))+1;
// 大尺度位置分：把 7 日区间平均切成 5 格，现价落在第几格
// 1 = 贴底，5 = 贴顶（C 恰好等于最高价时为 6）
// INTPART = 取整数部分

JC2:=INTPART((C-L)/((H-L)/5))+1;
// 当日力度分：把今天这根 K 线的振幅切成 5 格，收盘价落在第几格
// 5 = 收在当天最高附近（强势收盘），1 = 收在最低附近（弱势收盘）
```

### 1.3 本部分信号含义

ZXGL **不直接下单**，它是主策略的"守门员"：

- `AA1 && TT1` 同时为真 → 主策略才允许 **SK（开空）**；
- `ZZ1 && TT1` 同时为真 → 主策略才允许 **BK（开多）**；
- 周线横盘（TT=0）时，任何方向都不开仓——趋势策略最重要的防磨损设计。

## 2. XDD —— 大盘强弱标尺（跑在文华商品指数上）

### 2.1 变量字典

与 ZXGL 的工具变量完全同名同义，区别在于：**XDD 被套在文华商品指数（资产号 7186）上运行**，算出来的是"大盘基准值"，供主策略通过 `VAR1.K1`、`VAR1.JC1` 等方式读取对比。

| 变量 | 被主策略引用为 | 含义 |
|---|---|---|
| `K1` | `J1` | 文华指数现价相对 7 日最低价的涨幅 |
| `K2` | `J2` | 文华指数现价相对 7 日最高价的跌幅 |
| `JC1` | `JC1W` | 文华指数的 7 日位置分（1~5） |
| `JC2` | `JC2R` | 文华指数的当日力度分（1~5） |
| `ZD` | （未引用） | 文华指数 7 日中点 |

### 2.2 注释后代码

```mylanguage
// ============ XDD：强弱标尺（应用于文华商品指数 7186，被 #CALL 引用） ============
// 本指标不产生任何交易信号，只是一把"尺子"，
// 量出大盘当前的涨幅、跌幅、位置，供主策略与本品种对比强弱

ZD:=(HHV(H,7)+LLV(L,7))/2;                 // 大盘 7 日中点
K1:=(C-LLV(L,7))/LLV(C,7);                 // 大盘从 7 日低点的涨幅
K2:=(C-HHV(H,7))/HHV(C,7);                 // 大盘距 7 日高点的跌幅（负数）
JC1:=INTPART((C-LLV(L,7))/((HHV(H,7)-LLV(L,7))/5))+1;   // 大盘 7 日位置分
JC2:=INTPART((C-L)/((H-L)/5))+1;                        // 大盘当日力度分
```

### 2.3 本部分信号含义

XDD 自身无信号。它的输出在主策略里变成两条判断线：

- **本品种涨幅 > 1.5 倍大盘涨幅**（上半区）或**跌幅比大盘轻**（下半区）→ 强于大盘；
- 反之 → 弱于大盘。

## 3. 主策略（附件 `#CALL [7186 , XDD] A.txt`）

> 运行在你交易的具体品种上（分钟线或日线），是唯一**直接下单**的部分。

### 3.1 变量总字典

**① 外部引用区**

| 变量 | 来源 | 含义 |
|---|---|---|
| `VAR1` | `#CALL [7186, XDD]` | 文华商品指数 7186 上跑 XDD 指标的结果集 |
| `J1` | VAR1.K1 | 文华 7 日涨幅 |
| `J2` | VAR1.K2 | 文华 7 日跌幅 |
| `JC1W` | VAR1.JC1 | 文华 7 日位置分 |
| `JC2R` | VAR1.JC2 | 文华当日力度分 |
| `VAR` | `#IMPORT[WEEK,1,ZXGL]` | 周线上跑 ZXGL 的结果集 |
| `AA1` | VAR.AA | 周线空头许可 |
| `ZZ1` | VAR.ZZ | 周线多头许可 |
| `TT1` | VAR.TT | 周线非盘整许可 |

**② 相对强弱区（视觉信号）**

| 变量 | 含义 |
|---|---|
| `ZD` | 本品种 7 日中点 |
| `K1` / `K2` | 本品种 7 日涨幅 / 跌幅 |
| `PQ` | **强于大盘**信号 → 画红色 K 线 |
| `PR` | **弱于大盘**信号 → 画蓝色 K 线 |
| `OO` / `UU` | 涨幅比 K1/J1、跌幅比 K2/J2（强弱倍数，中间量） |
| `NN` | 7 日位置分 − 文华位置分（红字标在最高价上方，正=比大盘站得高） |
| `GG` | 当日力度分 − 文华当日力度分（绿字标在最低价下方） |

**③ M 头做空区**

| 变量 | 含义 |
|---|---|
| `HN30` | 距离 30 周期最高价过去了几根 K 线 |
| `HN8` | 距"右肩"（30 日最高点后 ≥8 根出现的更低局部高点）的根数 +1 |
| `LL` | 右肩处的最低价，近似**颈线位** |
| `KK` | 30 日区间按参数 **G1** 切出的**开空阈值**（下方） |
| `PP` | 30 日区间按参数 **G2** 切出的**平空阈值**（上方） |
| `PANZHENG` | 本周期盘整判定（7 周期振幅 < 均价 3%） |

**④ W 底做多区（与做空区镜像）**

| 变量 | 含义 |
|---|---|
| `LN30` | 距离 30 周期最低价过去了几根 |
| `LN8` | 距"更高局部低点"（底部抬高点）的根数 +1 |
| `HH` | 底部抬高点处的最高价，近似**颈线位** |
| `DD` | 按 G1 切出的**开多阈值**（上方） |
| `EE` | 按 G2 切出的**平多阈值**（下方） |

**⑤ 持仓量资金区（第三部分）**

| 变量 | 含义 |
|---|---|
| `RSV / K / D` | 标准 KDJ 的原始值与 K、D 线（NODRAW 不画出） |
| `MA5/MA10/MA30` | 5/10/30 周期均线 |
| `OPI30` | 持仓量 30 周期均值 |
| `XX` | 单日增仓 ≥4% 且涨幅 ≥3%（显著增仓获利） |
| `II` | 连续两日增仓 + 收盘创 2 日新高（连续增仓获利） |
| `ZC` | 增仓 ≥7% 或超 4 万手 + 涨 3%（超级增仓） |
| `KC` | XX 或 II 成立，且 KDJ 不超买（K<85 且 K 在 D 附近上方） |
| `SB` | **多头增仓信号**：近 5 根首次满足 KC，或超级增仓 ZC → 图标 ICO36 |
| `AA/BB/CC` | "洗盘后站起来"：两根前收阴、今收复实体上 1/3 + 洗盘量 >3% |
| `DSB` | **洗盘确认信号**：近 4 根首次满足 CC 且未创 10 日新高 → 图标 ICO43 |
| `MY` | SB 或 DSB 任一为真（多头资金进场综合标记） |
| `AAE/BBE/KKE/CCE` | 做空版"反击扑灭"：两根前收阳、今被砸进实体下 1/3 + 巨量换手 |
| `DSBE` | **空头扑灭信号**：近 4 根首次满足 CCE → 图标 ICO96 |

> ⚠️ **G1、G2 是自定义参数**，必须在公式参数表中赋值（如 G1=3、G2=2）。它们决定开平仓阈值在 30 日区间的分位，直接决定策略灵敏度。

### 3.2 逐行注释后代码

```mylanguage
// ================================================================
// 主策略：周线过滤 + M头/W底形态 + 文华强弱对比 + 持仓量资金确认
// 运行周期：交易品种的主图（分钟线/日线均可）
// ================================================================

// ---------- 第 0 部分：跨品种、跨周期引用 ----------

#CALL [7186 , XDD] AS VAR1
// 调用资产 7186（文华商品指数）上的 XDD 指标，结果存入 VAR1

J1:=VAR1.K1;     // 文华现价与七日最低价的涨幅（大盘涨幅基准）
J2:=VAR1.K2;     // 文华现价与七日最高价的跌幅（大盘跌幅基准）
JC1W:=VAR1.JC1;  // 文华的 7 日位置分
JC2R:=VAR1.JC2;  // 文华的当日力度分

// ---------- 第 1 部分：本品种 vs 文华指数的相对强弱 ----------

ZD:=(HHV(H,7)+LLV(L,7))/2;   // 本品种七日中点（强弱分水岭）
K1:=(C-LLV(L,7))/LLV(C,7);   // 本品种现价相对七日最低价的涨幅
K2:=(C-HHV(H,7))/HHV(C,7);   // 本品种现价相对七日最高价的跌幅（负数）

PQ:=C>ZD && K1>1.5*J1  ||  C<ZD && K2>0.7*J2;
// 强于大盘：
//   上半区时，本品种涨幅 > 1.5 倍大盘涨幅（领涨）；
//   下半区时，本品种跌幅比大盘轻（抗跌，注意 K2/J2 都是负数）
PR:=C>ZD && K1<0.7*J1  ||  C<ZD && K2<1.5*J2;
// 弱于大盘：上半区涨不动，或下半区跌得比大盘还狠

STICKLINE(PQ,C,O,COLORRED,0);   // 强势K线画红色实体
STICKLINE(PR,C,O,COLORBLUE,0);  // 弱势K线画蓝色实体
DRAWLINE(PQ,H,PQ,L,COLORRED);   // 补画红色上下影线
DRAWLINE(PR,H,PR,L,COLORBLUE);  // 补画蓝色上下影线

OO:=K1/J1;   // 涨幅倍数（本品种/大盘）
UU:=K2/J2;   // 跌幅倍数

JC1:=INTPART((C-LLV(L,7))/((HHV(H,7)-LLV(L,7))/5))+1;  // 本品种7日位置分
JC2:=INTPART((C-L)/((H-L)/5))+1;                        // 本品种当日力度分

NN:=JC1-JC1W;  // 7日位置分 − 文华位置分（正数=比大盘站得高）
GG:=JC2-JC2R;  // 当日力度分 − 文华当日力度分（正数=今天比大盘硬）
DRAWNUMBER(1,H,NN,0,COLORRED);    // 红字标在最高价上方
DRAWNUMBER(1,L,GG,0,COLORGREEN);  // 绿字标在最低价下方

// ---------- 周线过滤条件引入 ----------
#IMPORT[WEEK,1,ZXGL] AS VAR
AA1:=VAR.AA;   // 周线空头许可（周线收盘 < 7周均线）
ZZ1:=VAR.ZZ;   // 周线多头许可（周线收盘 > 7周均线）
TT1:=VAR.TT;   // 周线非盘整许可

// ---------- 第 2A 部分：M 头做空 ----------

HN30:=HHVBARS(H,30);
// 距 30 周期内最高价已经过去了几根 K 线

HN8:=BARSLAST( H<REF(H,1) && REF(H,1)>REF(H,2) && REF(HN30,1)>=8 )+1;
// 寻找"右肩"：前一根是局部高点（左右都低），
// 且这个高点出现在 30 日最高点之后至少 8 根（确保是见顶后的反抽，不是同一个顶）
LL:=REF(L,HN8);
// 右肩对应那根 K 线的最低价 ≈ M 头的颈线位

KK: LLV(L,HN30+1) + (HHV(H,HN30+1)-LLV(L,HN30+1))/G1;
// 开空阈值：30 日区间最低值 + 区间高度的 1/G1（低位分位线）
PP: LLV(L,HN30+1) + (HHV(H,HN30+1)-LLV(L,HN30+1))/G2;
// 平空阈值：位置比 KK 高（G2<G1），空头回到此线以上就离场

PANZHENG:= (HHV(H,7)-LLV(L,7))/MA(C,7) < 0.03;
// 盘整判定：近 7 根振幅不足均价的 3% → 死盘，不开仓

TT1 && AA1 && C<MIN(KK,LL) && PANZHENG=0, SK;
// ★★ 开空信号 SK ★★
// 周线空头许可 ∧ 周线非盘整 ∧
// 现价跌破（颈线 LL 与阈值 KK 中较低者）∧ 本周期非盘整

C>PP, BP;
// ★★ 平空信号 BP ★★：价格反弹收复 PP 线 → 空头止盈/止损离场

// ---------- 第 2B 部分：W 底做多（与 M 头完全镜像） ----------

LN30:=LLVBARS(L,30);   // 距 30 周期最低价过去了几根

LN8:=BARSLAST( L>REF(L,1) && REF(L,1)<REF(L,2) && REF(LN30,1)>=8 )+1;
// 寻找"抬高的底"：前一根是局部低点，且出现在 30 日最低点之后 ≥8 根
HH:=REF(H,LN8);        // 该点对应 K 线最高价 ≈ W 底颈线位

DD: HHV(H,LN30+1) - (HHV(H,LN30+1)-LLV(L,LN30+1))/G1;  // 开多阈值（高位分位线）
EE: HHV(H,LN30+1) - (HHV(H,LN30+1)-LLV(L,LN30+1))/G2;  // 平多阈值（比 DD 低）

TT1 && ZZ1 && C>MAX(DD,HH) && PANZHENG=0, BK;
// ★★ 开多信号 BK ★★
// 周线多头许可 ∧ 周线非盘整 ∧
// 现价突破（颈线 HH 与阈值 DD 中较高者）∧ 本周期非盘整

C<EE, SP;
// ★★ 平多信号 SP ★★：价格跌破 EE 线 → 多头止盈/止损离场

FILLRGN(BKVOL>0, DD, EE, COLORRED);    // 持多期间 DD~EE 画红色通道
FILLRGN(SKVOL>0, KK, PP, COLORGREEN);  // 持空期间 KK~PP 画绿色通道
AUTOFILTER;   // 信号自动过滤：保证开平仓严格交替，不会连续开仓

// ---------- 第 3 部分：持仓量资金信号（辅助判断，不直接下单） ----------

// —— KDJ 准备 ——
RSV:=(CLOSE-LLV(LOW,9))/(HHV(HIGH,9)-LLV(LOW,9))*100;  // 9日随机值
K:SMA(RSV,3,1),NODRAW;   // K 值（不画出）
D:SMA(K,3,1),NODRAW;     // D 值（不画出）

MA5:=MA(C,5);  MA10:=MA(C,10);  MA30:MA(C,30);   // 均线
OPI30:MA(OPI,30);                                 // 持仓量30周期均值

// —— 多头增仓识别 ——
XX: OPI>=1.04*REF(OPI,1) && C>1.03*REF(C,1);
// 显著增仓获利：持仓量单日 +4% 以上，同时价格涨 3% 以上 → 新钱在买
II: OPI>=1.04*REF(OPI,2) && REF(OPI,1)>REF(OPI,2) && C>HV(C,2) && C>1.015*L;
// 连续增仓获利：连续两日增仓，收盘创 2 日新高且远离当日最低价
ZC: (OPI>=1.07*REF(OPI,1) || (OPI-REF(OPI,1)>40000)) && C>1.03*REF(C,1);
// 超级增仓：持仓量 +7% 或绝对量增加 4 万手以上，同时大涨

KC:= (XX||II) && ((K>D || D-K<8) && K<85);
// 增仓条件 ∧ KDJ 条件（K 在 D 上方或即将金叉，且未超买）

SB: (KC && REF(EVERY(KC=0,4),1)) || ZC, ICON(0,'ICO36');
// ★ 多头增仓信号 SB：近 5 根首次满足 KC（只做第一次，避免追高），
// 或出现超级增仓 → 画图标 ICO36

// —— "洗盘后站起来"识别（多头加强版） ——
AA: C > HV(MAX(O,C),2)-1/3*(HV(MAX(O,C),2)-LV(MIN(O,C),2))
    && REF(C,2)<REF(O,2) && C-L>0.015*L;
// 两根前是阴线（先跌），今天收盘收复近两根实体区间的上 1/3，
// 且收盘远离当日最低价（站起来且获利）
BB: ABS(OPI-REF(OPI,1))+ABS(REF(OPI,2)-REF(OPI,1)) > 0.03*MIN(REF(OPI,1),REF(OPI,2));
// 总洗盘量：近两日持仓量变动绝对值之和 > 持仓的 3%（剧烈换手=洗盘）
CC:=AA&&BB;
DSB..CC && REF(EVERY(CC=0,3),1) && C<HHV(C,10), ICON(1,'ICO43');
// ★ 洗盘确认信号 DSB：近 4 根首次出现"洗盘后站起来"，
// 且未创 10 日新高（安全区）→ 画图标 ICO43

MY: SB||DSB;
// 多头资金进场综合标记：只要没跌破信号最低点，
// 这波新增资金就可能获利；坚持越久，筹码吸得越多

// —— 做空版："反击扑灭" ——
AAE: C < LV(MIN(O,C),2)+1/3*(HV(MAX(O,C),2)-LV(MIN(O,C),2))
     && REF(C,2)>REF(O,2)
     && HHV(MAX(O,C),3)-LLV(MIN(O,C),3)>0.02*L && ISDOWN;
// 两根前是阳线，今天收盘被砸进近两根实体区间的下 1/3，
// 三日振幅足够大且今日收阴 → 多头反击被扑灭，跌势延续
BBE: ABS(OPI-REF(OPI,1))+ABS(REF(OPI,2)-REF(OPI,1)) > 0.03*MIN(REF(OPI,1),REF(OPI,2));
// 洗盘量条件：多头巨量持仓被围歼
KKE: ABS(OPI-REF(OPI,1))+ABS(REF(OPI,2)-REF(OPI,1))+ABS(REF(OPI,2)-REF(OPI,3))
     > 0.05*MIN(REF(OPI,1),REF(OPI,2));
// 更严格的三日暴力洗盘条件（变动之和 >5%）

CCE:=AAE && (BBE||KKE);
DSBE..CCE && REF(EVERY(CCE=0,3),1), ICON(1,'ICO96');
// ★ 空头扑灭信号 DSBE：近 4 根首次"反击扑灭" → 画图标 ICO96

DSBE && OPI<0.98*REF(OPI,1), WORD(0,'减仓耗散筹码变轻');
// 扑灭后持仓量下降 → 是多头割肉离场，空头动能可能耗尽（提示文字）
DSBE && OPI-REF(OPI,1)>0.02*OPI, WORD(0,'增仓能量增强');
// 扑灭后持仓量反增 → 新空头还在加码，跌势能延续（提示文字）
```

## 5. 策略的交易哲学（一句话总结）

> **顺大（周线）逆小（等形态突破）、拒绝震荡（PANZHENG 过滤）、选强汰弱（对比文华指数）、资金验证（OPI 增仓配合）**——四个条件共振时才出手，持仓期间用通道色带管理离场。
