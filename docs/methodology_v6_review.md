# 日报方法论 v6：本项目的采用口径与偏离说明

评审日期：2026-09-23。依据项目根目录《期货看板日报_方法论与复制指南_v6.md》（v6.2，含 🟢 4h 蓄势池）。
该文档是判据来源；本项目实现版本为 `summary-v3.0`（`scan_version=3`）。这是判据一致性的实现，不是策略收益有效性的验证。

## 1. 相对 v5 实现（summary-v2.1）的变化

| 维度 | v5 实现 | v6 实现 |
|---|---|---|
| 分档 | 龙头三档（dual/absolute/quasi）＋分歧裁决树（板块氛围＋农/工分流＋抵抗特例 c1~c4）＋转折 A/B＋熊头遇压＋排名雷达 | 四档互斥按优先级取档：🥇绝对龙头 → 🔴危险分歧 → 🚀新贵 → 🟡回调，空头镜像（🐻/🔴/📉/🟡反抽）；⚪未入档中 4h 强者分流 🟢 蓄势池 |
| 动量 | 只有当日 1d/4h 评分水平 | 新增 **Δ4h 环比** = 今日日盘收盘 4h 评分 − 前一交易日日盘收盘 4h 评分，为危险分歧/新贵的核心判据 |
| 阈值 | LEAD_1D=4.5 / LEAD_4H=1.0 / ABSO_1D=10 / QUASI_1D=3.0 / TIER_4H=−0.5 | LEAD_1D=4.5 / LEAD_4H=1.0 / D4H_SIG=1.0 / NEW_STRONG_4H=1.0（其余删除） |
| 报告结构 | 9 节 HTML | 五节固定模板：核心判断（当日信号动作＋judge-card）/ 多头四档表 / 空头镜像四档表 / 🟢蓄势池 / 动量异动榜 / 操作提示 ＋ 固定头尾 |

## 2. v6 规则的实现要点

- **优先级互斥**（`_classify`，scan_report.py）：满足即定档，不再往下走。
  1. lead：日线持多 ＋ 1d ≥ 4.5 ＋ 4h 在 long_trend 桶 ＋ 4h ≥ 1.0
  2. danger：日线持多 ＋ 4h 偏弱（掉桶 或 4h < 0）＋ Δ4h ≤ −1.0
  3. fresh：日线持多 ＋ Δ4h ≥ +1.0 ＋ 4h > 1.0（**4h 强势前置**，负值区回抽不入新贵）
  4. pull：日线持多 ＋ 1d ≥ 4.5 ＋ Δ4h > −1.0
  5. 其余 ⚪；⚪ 中 4h 在桶且 4h > 1.0 → 🟢 蓄势池。空头侧符号取反镜像。
- **Δ4h 缺失**（前一交易日 4h 评分不可得）：Δ 栏标「—」，danger/fresh 无法确认，
  按当日状态落入 pull/flat 并记 `provisional=True`（报告加 ※）。
- **桶归属**：`long_trend`/`short_trend` 桶即 4h POS=±1（screen.py 主筛口径），以桶列表为准。

## 3. 与 v6 文档的偏离（有意为之）

1. **Δ4h 数据源**：文档 §4 要求读前一交易日归档快照。本项目改为从 `data/4h/json/*.json`
   全量 K 线**精确重算**（4h 评分 = 收盘对 MA7 偏离%，纯函数），不受快照积累限制；
   归档快照仍用于头部多空计数基线。重算取**日盘收盘 bar**（时刻 ≤15:30 的最后一根），
   夜盘 23:00 bar 按源标签属当日日历日但实际是次一交易日夜盘，不计入「前一交易日收盘」。
2. **锚点样板**：文档钦定的 `daily_report_2026-09-22_v6.html` / `TEMPLATE_daily_report_v6.md`
   不在仓库。HTML 骨架按 §3.1 的文字描述与固定类名清单重建
   （.header/.oneline/.card/.judge-grid/.judge-card/.note/.lead .pull .danger .bear .fresh .flat/.foot）；
   用户后续提供样板后放入 `docs/anchor_v6/` 再逐节对齐视觉。
3. **v5 数据诚信守卫保留**（与 v6 不冲突，属实现正确性而非判据）：
   SP 平多 / BP 平空区分；破位与评分独立核验（多头侧破位 = 4h 收破 EE，空头侧镜像 = 4h 上破 PP，
   仅作备注词不单独设档）；未知评分不补零；`close is None` 旧合约过滤；
   两周期行情日同步校验；叙事与事实 input_hash 绑定。
4. **边缘情形**：日线 ≥4.5、Δ4h ≤ −1.0 但 4h 不弱（在桶且评分 > 0）的品种按规则落入 ⚪
   （如 sc 原油 1d 20.80 / 4h +0.32 / Δ4h −5.97）。v6 文档 09-16 示例把 sc 归入回调档，
   其示例写于 Δ4h 规则正式化之前，且示例未公布当时 Δ4h；以规则表为准。
5. 农/工分流、熊头遇压、转折 A/B/C、EE 生死线清单、排名雷达独立成节均按 v6 删除；
   排名轨迹保留为四档表列，排名异动（|Δrank|≥3）并入动量异动榜末尾。
